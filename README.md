-- DEBIAN ALIGHT BOOTSCREEN --
--        by CardyRGB       --

This is a bootscreen for Debian made in Alight Motion, so you're not stuck with the boring, motionless Debian splash.

-- DEPENDENCIES --

You need a Debian installation with Plymouth managing the boot screen
If not, run:
sudo apt install plymouth plymouth-themes

-- IMPORTANT!!! --

INSTRUCTIONS ONLY WORK ON DEBIAN (most likely, I haven't tried Fedora so idk)
THIS BOOTSCREEN IS MADE FOR 1080p60 DISPLAYS
